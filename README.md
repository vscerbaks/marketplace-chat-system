# Marketplace Chat System

Automation interface for managing marketplace chats through Telegram.

This project connects marketplace communication workflows with a Telegram bot interface, allowing operators to manage chats, notifications, and responses without manually using the marketplace web interface.

## Features

- Telegram bot interface for marketplace chats
- Browser automation for chat management
- Real-time notifications
- Message synchronization
- Workflow automation for operators
- Simplified communication management

## Tech Stack

- Python
- Playwright
- Telegram Bot API
